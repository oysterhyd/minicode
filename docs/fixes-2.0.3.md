# MiniCode 2.0.3 代码审查与修复

本次从实现和跨模块调用路径入手审查。既有测试仅用于回归验证；另写了独立协议服务、CLI 子进程、真实 Git 仓库、进程取消和界面事件时序复现。保留 Rust Runtime、MyGo Desktop、Ink TUI 与 schema 7，不改变模型账户或个人数据。

## 具体修复

| 范围 | 原问题 | 修复后的行为 |
| --- | --- | --- |
| 文件读取 | 空文件被误判为 offset 越界，Agent 无法正常检查新建空文件。 | 首次读取空文件返回成功；真正超出范围的 offset 仍报错。 |
| 文件编辑 | read 按逻辑行显示 LF，edit 却要求 Windows 文件原始 CRLF，模型提供的多行文本无法匹配。 | 小文件和大文件编辑都接受对应的 LF 文本，并保留原文件一致的 CRLF 格式。 |
| 文件搜索 | 在 src 或 src/file.txt 中搜索时只返回 file.txt，后续 read 会指向错误位置；max_results 可无限增大。 | 结果始终使用工作区相对路径；参数限定为 1–1000，执行层也保留上限。 |
| 命令输出 | tail 移除末尾换行后，普通输出被误判为截断，每次都产生归档。 | 末尾换行不再触发归档；真实长输出继续有界预览和分页。 |
| 命令原文 | Windows 自动转换 /dev/null 的正则也会改写引号内的字符串，实际执行内容与审批文本不一致。 | 保留命令原文；Windows 提示词明确要求使用 PowerShell 的 $null。 |
| 命令取消 | Windows Job Object 终止后没有等待后代退出，任务已显示停止但子进程仍短暂占用工作目录。 | 主动终止所属进程树，并等待 Job 中进程退出后完成清理；新增真实 Node 后代进程复现。 |
| 项目指令 | bash 的 cwd 没有发现子目录 AGENTS.md；嵌套 AGENTS.md 可以通过链接读取工作区外文件。 | 命令工作目录执行相同的指令预检和重新请求屏障；拒绝链接或 junction 指令文件。 |
| 项目指令恢复 | 会话启动后才出现的根 AGENTS.md 没有记录摘要；重扫扩展还会丢失已经加载的子目录指令。 | 新指令变化记入会话事件；扩展刷新保留固定的项目指令和已激活技能摘要。 |
| Skills | 同名项目技能和用户技能导致整个会话启动失败；工具 skill_load / skill_unload 没有写激活事件，重启后丢失。 | 项目技能覆盖同名用户技能；工具激活和卸载写入持久事件，恢复时校验正文摘要。 |
| 子助手验收 | 子助手继承父会话 acceptance，探索任务也可能运行父任务的验收命令，造成重复执行和权限范围外副作用。 | 子助手不创建或执行父验收 Goal；验收由父任务统一运行。 |
| 验收证据 | 新验收失败后仍保留旧通过证据；工作区指纹忽略依赖 / 缓存等目录，旧通过证据可能掩盖当前检查失败；缺失的受保护文件被创建成目录仍判为未改变。 | 每次准备完成任务都执行当前验收，失败立即清除旧证据；受保护路径必须是普通文件或保持不存在，目录不会被当作有效文件基线。 |
| 子助手上下文与结果 | 子助手未继承父会话已加载的技能和子目录指令；结构化结果只校验数组，不校验数组元素。 | 复制父任务固定指令和激活技能；findings / evidence_refs / unresolved 必须为字符串数组。审批清理限定子会话自身。 |
| Token 预算 | 累计用量恰好等于上限时仍可执行写入或再发请求。 | 达到上限即暂停，补齐未执行工具结果，阻止后续副作用。 |
| 异常响应用量 | 响应因重复调用 ID 等协议错误被拒绝时，已经报告的 token 用量也被丢弃，恢复后脚本可能再次播放错误响应。 | 拒绝副作用前先原子记录已报告用量和脚本进度；恢复累计这些记录，不重复播放。 |
| 工具恢复 | 历史压缩后遗忘旧 tool call ID，模型复用 ID 可能再次执行副作用并覆盖结果日志。 | 持久事件中的调用 ID 始终保留在运行时已用集合；压缩后仍拒绝复用。 |
| 上下文压缩 | 最初用户要求被压成 240 字预览，后半段约束可能丢失；/compact 仍使用自动触发条件，低于阈值时不起作用。 | 完整保留最初用户消息和最近交互；手动压缩主动寻找可归档历史，只有能减少上下文时才归档，并使用模型校准后的窗口。 |
| 会话并发 | 已加载的 Runtime 可以覆盖另一进程后续写入的历史；第二进程可以删除运行中的会话；已删除的空会话仍可能运行工具并写孤立记录。 | Bridge 发现外部更新后先重新加载，再接受新输入；获得锁后再次核对持久消息和会话存在性。删除也必须获得相同会话锁。 |
| 附件 | 同一内容以不同文件名导入时，内容寻址元数据被新名称覆盖，旧消息 encoded 校验失败。 | 校验内容 ID、类型、MIME 和大小；名称属于各条消息的引用，旧会话继续可读。 |
| 截断响应 | OpenAI / Anthropic 输出达到上限时，未完成的工具 JSON 被直接解析成协议错误。 | 丢弃截断响应中的工具调用，保存用量，继续请求完整回复；不执行不完整写入。SSE 和普通 JSON 响应均处理。 |
| SSE | 模型逐行解析 data，不能正确处理多行事件；MCP 的两套解析器遗漏 CR 单独换行和 BOM。 | 模型、Streamable HTTP MCP、旧 SSE MCP 共享增量解码器，处理 LF / CRLF / CR、BOM、多行 data、注释和跨块 UTF-8；按事件实施大小限制。 |
| MCP 生命周期 | 初始化通知没有总超时；多个服务器串行探测；无工具的连接没有保留在注册表中。 | 整个发现过程有超时，最多四个独立服务器同时探测；所有成功连接都由注册表持有和关闭。 |
| MCP 协议 | stdio 对不支持的服务端请求不回复，服务端会一直等；普通 HTTP JSON 响应未核对请求 ID。 | 回复标准 method-not-found 错误；拒绝不匹配的 JSON-RPC 响应 ID。 |
| 插件完整性 | 指纹直接拼接文件名和内容，例如 a + bc 与 ab + c 的输入相同。 | 指纹加入文件名长度和文件内容长度；锁文件记录 fingerprint_format=2，消除边界歧义。 |
| 模型设置 | 配置了假模型脚本环境变量后，显式 setModel 仍可能强制选择 fake；重复选择同一 fake 会从头播放脚本。 | 显式模型选择优先；相同脚本身份保留进度和工具计数。空资源 / 脚本环境变量按未配置处理。 |
| 模型能力与配置 | setEffort 在空闲时可以绕过模型 supportsEffort；sendPrompt 隐式切模型没有同步会话摘要；删除服务后选择可能指向失效模型。 | 按 Provider 能力拒绝不支持的强度；同步模型和服务摘要；失效选择切到可用默认模型。配置写入也检查 4 MB 限制，避免写出无法再打开的文件。 |
| 配置输入 | 带 UTF-8 BOM 的配置或 CLI 脚本无法读取；复制的地址 / 密钥有首尾空白时连接测试与正式连接行为不一致。 | 读取配置和脚本时处理 BOM；统一规范化地址与密钥，空白密钥继续保留已有密钥。 |
| TUI Provider | --provider 可以验证环境密钥并选模型，但 sendPrompt 又强制要求保存的服务行，无法真正发起对话；内置 Anthropic 的 effort 被接受却不发送。 | 没有服务行的模型使用同样的 Provider 凭据校验；失效的服务限定模型仍拒绝。Anthropic 明确保持 off，并拒绝不支持的强度。 |
| CLI 错误恢复 | 无效 /permissions、/model、/resume 或技能操作会直接退出整个聊天。 | 命令错误显示后继续接受输入；模型、权限和技能无参数时展示当前值或列表。 |
| CLI 输入与切会话 | spawn_blocking 读审批输入可能在取消后继续阻碍退出；/resume 的设置模型没有更新，下一轮又切回原会话模型；/new 验收设置不一致。 | 单个脱离 Tokio 阻塞池的输入线程，审批和 Ctrl+C 使用异步选择；恢复时同步模型及该会话 token 上限，新会话沿用当前预算 / 验收并清除记住的授权。 |
| CLI 脚本与数据库 | --script 在 Runtime 恢复后设置，错过进度恢复而重播写入；全局 --db 被 TUI 启动器丢掉；相对数据库路径的空父路径导致创建失败。 | 设置脚本后按身份恢复响应 / 子助手进度；向 TUI 传递绝对数据库路径；正确处理相对文件的当前目录。 |
| CLI 输出与报告 | 不可信文件或模型文本中的终端控制字符直接输出，可清屏或触发 OSC 剪贴板控制；工具失败但没有普通输出时不显示原因；文本 report 忽略 --output。 | 显示工具 / 模型文本及导出文本报告时过滤控制字符，显示真实错误；文本报告按指定路径原子写入。原始持久消息和归档保留。 |
| TUI 协议 | reasoning_delta 被当作未知事件，直接毒化连接和所有后续请求。 | 接受合法思考事件；请求有 35 秒超时，写入前检查 4 MB 协议限制，并清理计时器。 |
| TUI 队列 | 用户点击停止与正常结束交错时，正常结束会重新允许队列自动执行；失败的 /resume 提前清空队列。 | 停止意图优先保留队列，Enter 可手动继续；会话切换成功后才清空旧队列。 |
| TUI 会话切换 | 完成事件触发的后台 getState 携带旧 sessionId；若晚于 /new 或 /resume 到达，桥接会重新选中旧会话，下一条输入可能进入旧上下文。 | 后台刷新只观察当前客户端选择，不再携带可触发恢复的会话 ID；本地版本检查继续拦截陈旧响应。以真实 Rust 桥接和受控请求延迟复现，确认新会话不会被后台读操作恢复。 |
| Desktop 状态 | /continue 的 run_done 比请求响应早时，回调又把 Busy 设回 true；旧 getState 回调会覆盖较新的设置。 | 继续任务在请求前进入运行状态；完成事件不会被迟到响应翻转；状态请求用递增版本过滤陈旧结果。 |
| Desktop 停止与断线 | 停止竞态会继续排队任务；部分致命桥接错误没有 exited 关键字，界面一直运行；重复状态查询还会覆盖原始错误。 | 尊重停止意图；桥接客户端发送 fatal 标志，界面封存待执行工具 / 审批并保留队列和原始错误。 |
| Desktop 输入与历史 | 未选工作区时提交会丢失输入；加载历史期间也可清空草稿；重试附件消息时只重发文字；历史中只有持久 tool_result 的结果被误显示为中断。 | 保留草稿和附件，加载期间不提交；重试保留附件；历史回退到已送达结果并展示实际错误。 |
| Desktop Git | exec.Command 查找 Git 使用宿主 PATH，忽略包内配置；文件名中的方括号等被 diff 当作 pathspec。 | 从传给子进程的 PATH 定位 Git；单文件 Diff、暂存、取消暂存和跟踪查询使用 literal pathspec。 |
| 工作区 Git 范围 | 在仓库子目录打开工作区时，“暂存全部”暂存整个仓库；status 返回仓库根相对路径，文件预览和统计错位。 | 全部暂存限定当前目录；状态按仓库前缀转换为工作区相对路径，Diff / numstat 同步限制范围。 |
| 发行审计 | 环境凭据识别遗漏更新签名私钥、通用 token 等名称，普通文件中包含这些值时可能漏检。 | 纳入 PRIVATE_KEY / SIGNING_KEY / TOKEN 等变量，并以独立产物目录验证：发现值即拒绝发布，错误消息只显示文件名。 |

## 升级说明

已有配置、schema 7 数据、会话、附件和项目记忆继续使用。若项目已有旧版 `.minicode/plugins.lock.json`，需要审查本地插件后运行 `minicode plugins lock --workspace <项目目录>` 生成格式 2 的指纹；不要自动接受未知插件内容。

本次提供的是代码级可靠性修复，未将 Claude Code / Codex 的模型能力、沙箱、OAuth、远程执行或 worktree 调度等全部实现。协议验证使用独立本地服务和可复现脚本，未以此宣称真实模型的推理能力或长任务成功率等同于那些产品。

验证记录与公开安装包摘要见 [发行核验](../release/VERIFICATION.md)。新增复现位于 `agent/tests.rs`、`agent/sse.rs`、`tests/agent/audit.test.mjs`、TUI 的 `audit-regressions.test.tsx`，以及 Go 的 `audit_regression_test.go`、workspace / model 测试。

SSE 解析按照 [WHATWG 事件流规则](https://html.spec.whatwg.org/multipage/server-sent-events.html#event-stream-interpretation)处理，MCP 请求 / 响应边界参考 [MCP 官方传输规范](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)。
