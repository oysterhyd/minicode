# 2.0.1：压缩、文件预览与 MCP 回归修复

2.0.0 在每轮模型请求前，无条件归档超过 16KB 的工具结果，并发送 context_compacted 事件。因此新会话写入较大的 HTML 后，即使上下文负载很低，也会出现压缩提示并截短最近的结果。2.0.1 先按上下文阈值执行正常压缩，仅在压缩后仍超过硬上限时才归档大块结果。小窗口的预留量不再直接扣除固定 16,384 token，而是最多占窗口的 10%。

Desktop 的写入详情此前同时显示源码前 40 行和原始 Diff，两者字体与行距不同；源码行还是外层容器的直接子项，逐行多出 8px 间距。现在写入和编辑共用既有 Diff 组件，优先显示实际工具结果中的行号及增删，结果到达后刷新缓存，移除重复文本。展开完整 Diff、失败输出和完整归档入口保留。

MCP 需要初始化以发现可提供给模型的工具。启动探测失败仍记录在会话事件中，并可在 MCP 的连接检测中查看，但不会在未调用工具时生成对话警告。相同服务器身份只初始化一次；缺少配置所需环境变量时，返回变量名并停止启动。真正的 MCP 工具调用失败仍显示在对应工具结果中。

补丁升级继续接受同一主／次版本中较早补丁版本的插件；例如原有 2.0.0 插件可在 2.0.1 使用，未来补丁及不同主／次版本仍拒绝。

回归覆盖：Rust 28 项单元测试；原生集成 46 项；Ink 83 项；Go 全量、静态检查与文件预览浅／深色布局检查。新增大文件首轮回归同时断言：没有压缩事件、最近结果完整保留、文件尾标记仍可读取。MCP 的连接诊断和实际调用错误分别验证。
