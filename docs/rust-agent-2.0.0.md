# Rust Agent 2.0.0 迁移与验收

整个 Agent 后端、项目命令、评测宿主与报告生成改为 Rust。TypeScript + Ink TUI、Go / MyGo Desktop 保持现有技术栈、界面组件、主题和交互。前端只修改后端启动位置和包内工具 PATH。

Python 核心、Python 测试、解释器依赖与打包脚本已删除，旧 Python TUI 与 Electron 对照实现清除。当前源码只保留 Rust 后端、现用前端、Node.js 评测夹具和所需构建工具。历史性能报告保留为旧版证据。

## 功能兼容

| 功能 | 验证方式 |
| --- | --- |
| NDJSON v2、多会话、取消与审批 | 真实后端集成与前端桥接测试 |
| OpenAI / Anthropic 流、工具、媒体与用量 | 本地 HTTP 服务、碎片 UTF-8、重试与取消 |
| 文件读写、Diff、大文件搜索、命令与归档 | 原生工具、工作区边界、分页、后台输出与时间预算 |
| SQLite、任务 DAG、记忆、恢复 | schema 3→7、未来版本拒绝、未知副作用不重放、结果日志恢复 |
| 指令、技能、插件、本地资源与 MCP | 指令顺序、摘要冻结、插件锁、stdio / HTTP 测试 |
| 子助手 | 工具子集、审批路由、证据验证、累计用量、只读并发 |
| 内置评测 | 20 道题 × B0/B1/B2；3 场景含验收失败续跑，独立隐藏断言 |
| UI | Ink 原有测试、MyGo 快照及交互测试，实际安装窗口烟测 |

旧 schema 3–7 继续使用原 SQLite 格式和用户目录。模型配置、附件及项目记忆保持原身份摘要。现有更新公钥不变，更新替换整个 runtime 目录。

## 简化与优化

- 一个原生可执行文件统一 CLI / bridge / runtime / eval，移除解释器和 Python 依赖树。
- 工具 schema、正则和模型目录缓存后复用；SSE 参数以字符串缓冲区追加，避免逐片重建 JSON 字符串。
- 工具调用 / 结果配对一次线性扫描，目录分页采用确定性 DFS；任务依赖用线性图遍历，任务解锁用集合 SQL。
- 大文件编辑与搜索借用文件映射，分页有界读取；长输出写磁盘并保留预览。归档游标最多缓存 16 文件 × 64 检查点，连续翻页不重复扫描完整前缀。
- 状态轮询复用上下文摘要和增量统计；只读工具最多并发 4 个，只读子助手最多并发 2 个。命令 / MCP 的进程树由 OS 管理并回收。
- 发行构建使用优化、LTO、符号裁剪及静态 CRT；生产 Ink 依赖继续去掉类型声明与 source map，许可和运行数据保留。

## 测量方法

使用 v1.3.2 实际发行的 Python 3.12.12 环境作为基线，在同一台 Windows x64 机器、独立空白用户目录下与新发行 Rust 程序交替测量。离线脚本避免网络与模型生成时间干扰。

`scripts/benchmark-agent.mjs` 测量冷启动到首次 getState、25 轮模型 / 48 次只读工具、2000 条各 10k 字符历史，以及活动会话状态轮询。每项 7 次，报告中位数，并记录进程工作集、私有提交、峰值工作集及 CPU 秒。安装器与安装内容直接按最终产物字节计数。

最终安装包、性能原始记录、代码行统计及完整发行验收将在构建核验后写入本报告。原型 GNU 构建不作为最终 MSVC 发行指标。

这些指标描述本地 Agent 开销，不能解释为远程模型生成或网络等待同幅提速；前端 Node / Go 进程的内存需与 Agent 单独区分。
