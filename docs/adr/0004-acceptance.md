# ADR 0004: 宿主验收决定目标完成

状态：已采用（2026-09-23）

## 背景

模型的最后一句“已完成”不能证明测试通过，也不能证明受保护文件没有被改动。未提交改动使 Git HEAD 不足以标识当前代码状态。

## 决策

用户提供的验收配置由宿主加载，模型不能通过工具修改它。无工具调用的模型回复触发命令、产物和受保护路径检查。通过证据绑定工作区内容指纹；文件变化后重新验收。失败详情回填给模型，在次数或预算上限处暂停。评测 runner 在 Agent 工作区外再次独立检查命令、受保护文件和允许修改范围。

## 后果与证据

检查命令本身有时限和输出上限；语义要求仍需人工审查。`tests/test_goals.py` 验证证据失效，`tests/test_runtime_p1.py` 验证失败续跑，`evals/run_real_eval.py` 保留每次独立判分结果与会话 trace。
