# ADR 0003: 原始产物与模型工作集分离

状态：已采用（2026-09-23）

## 背景

长命令输出和多轮工具结果会超过模型窗口。直接截断会丢失调试线索，随意删除消息还会拆散工具调用与结果。

## 决策

工具完整输出先归档到会话 artifact，再给模型有界预览和 `read_artifact` 引用。上下文超阈值时按完整交互组归档旧历史、缩短旧工具结果，并在必要时生成结构化摘要。初始用户要求和验收约束保留；压缩前后验证调用与结果配对。原始事件和产物用于审查，压缩后的消息是模型工作集。

## 后果与证据

归档支持按字符分页回读，但本地 token 估算并非服务端精确计数。服务端拒绝超长上下文时只做有界补救，仍失败则保存会话并明确暂停。`tests/test_context_compact.py` 与 `tests/test_runtime_p1.py` 覆盖配对、归档和长输出；在线评测记录压缩事件，不把 FakeProvider 的固定 usage 当成本收益。
