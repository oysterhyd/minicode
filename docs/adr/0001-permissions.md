# ADR 0001: 工具权限门与执行隔离

状态：已采用（2026-09-23）

## 背景

模型、仓库文件、Skills 和 MCP 返回值都不能授予自身权限。编码 Agent 需要执行写入和 Shell，但命令字符串过滤无法限制任意代码的副作用。

## 决策

内置读取工具默认允许；编辑与 Shell 在默认模式下逐次审批；未知工具拒绝；MCP 工具逐次审批。参数先按工具 schema 校验并规范化，再将同一份参数送入权限门、审批展示和执行。审批范围是当前调用，不复用到变化后的参数。`bypass` 是用户显式选择的可信本地模式，不表示沙箱。

## 后果与证据

无效参数不会弹出审批，也不会运行工具。`tests/test_runtime_task_board.py::test_invalid_write_arguments_never_request_approval` 锁定该顺序；路径越界、符号链接逃逸和命令超时另由工具测试覆盖。当前执行环境是本机进程；不声称对不可信仓库提供 OS 级隔离。需要运行未知代码时，应在外部受限环境内启动整个 CLI。
