# MiniCode 交互规范（阶段 7）

协议版本保持 2；新增能力通过 initialize.capabilities 声明，可选字段缺失时沿用旧行为。

## 会话与命令

- 会话使用完整 ID 或任意非空且唯一的前缀；空参数列出最近会话，歧义不自动选取。显示 ID 仅为缩写，不是标识符。
- `/resume [ID]` 恢复消息、用量与已保存预算。显式命令行预算优先于会话预算；未指定时恢复保存值。
- `/new` 与 `/clear` 开启新上下文，保留旧会话以供恢复。迁移：原 `/clear` 清屏行为改名 `/cls`，只隐藏显示，不改持久化消息。
- 会话切换不迁移消息队列。运行中的上下文重置必须先取消并等待结束。
- `/cost` 报告实际可得的统计；未知费用显示不可用，不能虚构价格。`/context` 使用运行时上下文估算。
- 无底层支持的命令明确报告依赖，不返回虚假成功。`/rewind`、`/undo` 依赖 G3；高级任务编辑依赖 G4；记忆管理演进依赖 S3。

## 输入与中断

优先级：审批 → 弹窗/菜单 → 运行/取消 → 草稿/历史编辑 → 空闲。

- 审批：Y 仅本次允许、A 本会话允许规则、P 写入项目规则、N/Esc 拒绝。不可记住的操作不提供 A/P。快捷键一次只作用于第一张待处理审批卡；请求处理期间不跳至下一张。
- Esc 先关闭弹窗/菜单；无更高优先级界面时，运行中取消一次。空闲双击 Esc（400ms 内）把上一条用户消息复制到草稿。编辑重发作为新消息追加，保留原历史；撤销文件变化属于 G3。
- Ctrl+C：运行时首次正常取消，取消中再次退出；空闲有草稿则清空，空草稿两秒内再次按下退出。Ctrl+D/退出命令退出。空 Enter 不取消任务。
- 上下键优先导航补全菜单；多行草稿内部移动光标，到首/末行再浏览输入历史，离开历史恢复未提交草稿。
- bracketed paste 作为一次输入；长文本折叠为可预览引用，发送时展开。附件导入失败保留草稿。

## 服务端队列

- `steer` 在当前工具结果持久化之后、下一次模型请求之前追加为用户消息；不会修改已经发出的请求。
- `followUp` 在当前 run 正常完成后自动启动下一 run。队列按接受顺序处理，客户端不再重复调度。
- 如果 steer 接受后没有下一工具边界，正常完成时作为下一 run 执行。取消、失败时保留未消费消息为暂停状态，须显式继续或删除，不能自动重试副作用。
- 队列由会话持有，使用独立消息 ID 支持列出和删除；已消费消息不可删除。会话切换不搬运、不隐式重发队列。

## 终端输出

普通终端滚屏保存完成条目；活动区域只保留未完成输出和输入。默认不启用备用屏或鼠标捕获，原生选择、复制与回滚由终端负责。大输出默认预览，完整 artifact 按页读取，错误可重试。
