## 仍需如实保留的边界

- 20 题真实结果为 B0 47/60、B2 51/60，误报完成均为 0；运行时工作树有未提交改动，且 4 并发导致明显的时长上限失败，不能把差距当作 B2 的收益。[评测分析](evaluation-20260923.md)和[原始结果](../reports/eval-real-20260923/results.json)列出全部运行。用户选择不再追加第二批 120 次 API 对照，因此本轮没有“固定源码、交替串行”的发布级效果测量。
- 补充场景的完整真实模型重复评测已按用户要求停止；已完成的两条记录仅保存在本地，不计入发布结果。[离线场景结果](../reports/eval-scenarios/summary.md)仅证明 FakeProvider 驱动下的机制分支。
- [MP4](../reports/demo/pagination-real-trace-replay.mp4)是由真实模型事件生成的历史执行压缩回放，不是实时屏幕录制。现场 8–10 分钟演示流程见[演示脚本](demo.md)。
- 命令执行是在本机可信开发环境中进行；审批与路径门不能隔离被允许运行的任意 Shell。容器隔离、远程 MCP、定时任务和写入型多代理均未作为当前 CLI 核心版能力宣称。
- 本地验证环境为 Windows Python 3.12。跨平台 CI 需要在有 Git remote 的仓库触发并检查结果；未运行的 CI 不视为通过。
