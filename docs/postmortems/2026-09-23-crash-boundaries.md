# 复盘：工具副作用与结果落库之间的不可原子窗口

日期：2026-09-23。性质：受控故障注入。

## 现象

模拟写入工具在执行前、执行后但结果未保存、结果已保存后三处中断。第二种情况里文件已有一次写入，但会话没有可用的结果消息；自动重试会造成重复副作用。

## 处理

恢复流程依据持久化的 tool result 判断是否已经结算。没有结果的写入调用标记 `SIDE_EFFECT_UNKNOWN`，不再自动执行；模型先读取文件核实。已有结果的调用直接进入后续模型轮次。

## 验证与限制

`tests/test_crash_windows.py` 的三种注入场景均验证恢复后写入计数不增加。该策略无法从缺失的结果记录推断第一次执行是否成功，故意保留“未知”状态。用户仍需核实外部系统或 Shell 命令的真实效果。
