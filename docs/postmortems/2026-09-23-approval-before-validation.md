# 复盘：无效工具参数先触发审批

日期：2026-09-23。性质：代码审查发现的权限协议缺陷。

## 现象

Runtime 在工具内部校验参数之前先询问权限。对于缺少必需字段的写入请求，用户可能看到审批提示，随后工具才报告参数无效。展示参数与实际工具规范化后的参数也没有统一入口。

## 原因与修复

工具 schema 校验只存在于 `BaseTool.run`；Runtime 不知道规范化结果。现在每个工具提供 `validate_args`，Runtime 在权限检查前调用，并用同一份规范化参数审批及执行。MCP 工具按发现的 JSON Schema 校验。

## 验证与残余风险

`test_invalid_write_arguments_never_request_approval` 验证无效 `write` 没有审批事件也没有文件写入。权限门仍是用户授权机制；本地执行器不是安全沙箱。
